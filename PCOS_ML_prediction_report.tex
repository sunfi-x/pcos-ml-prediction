\begin{abstract}
Polycystic Ovary Syndrome (PCOS) affects 8--13\% of women of reproductive age and is
frequently under-diagnosed due to heterogeneous symptom presentation and limited access to
clinical testing.  This study presents a machine-learning-based screening framework trained
on 541 patients from 10 hospitals in Kerala, India (177 PCOS, 364 non-PCOS).  Nine classifiers
were evaluated under 30-fold repeated stratified cross-validation with an untouched 20\%
held-out test set (109 patients).  All preprocessing, feature selection, and SMOTE
oversampling were encapsulated inside each fold to prevent data leakage.  The best
cross-validated model, Random Forest with a 20-feature correlation-based subset, achieves
CV ROC-AUC $0.957 \pm 0.017$ and held-out test AUC $0.945$ (95\% CI: $[0.887,\,0.991]$).
A dedicated experiment shows that applying SMOTE and feature selection \emph{before} CV
inflates accuracy by $+2.7$ pp and F1 by $+8.3$ pp on the same data.  SHAP analysis
identifies follicle count and the hyperandrogenism symptom cluster as primary predictors,
consistent with the Rotterdam diagnostic criteria.  A questionnaire-only model (no lab or
ultrasound) recovers 93\% of the full model's AUC, suggesting a viable low-cost screening
pathway.  This framework is intended for academic research; external clinical validation is
required before any deployment.

\section{INTRODUCTION}
% ============================================================

\subsection{Background and Motivation}
PCOS is the most common endocrine disorder in women of reproductive age, with a global
prevalence of 8--13\% \cite{rotterdam2004}.  It is the primary cause of anovulatory
infertility and carries elevated risk of metabolic syndrome, type 2 diabetes, and
cardiovascular disease.  Diagnosis follows the 2003 Rotterdam criteria, requiring at least
two of: oligo/anovulation, hyperandrogenism, and polycystic ovarian morphology.
Up to 70\% of affected women remain undiagnosed in primary care \cite{zad2024} due to
variable symptom expression, ultrasound costs, and limited endocrine testing access.
Machine learning offers potential for automated, lower-cost screening using questionnaire
and anthropometric data.

\subsection{Research Gap and Objectives}
A review of five recent papers on this dataset identified five recurring weaknesses:
(1)~data leakage from preprocessing before cross-validation;
(2)~unaddressed class imbalance (2.06:1 ratio);
(3)~single train/test splits with no uncertainty quantification;
(4)~absent explainability; and
(5)~no comparison against established clinical baselines.

This project addresses all five gaps.  Concretely, it:
builds a leakage-free encapsulated pipeline and \emph{measures} the inflation a leaky
protocol produces;
compares nine classifiers with bootstrap confidence intervals;
provides SHAP global and patient-level explanations;
benchmarks ML against clinical decision rules; and
quantifies the value of progressively cheaper feature tiers.

\subsection{Data Cleaning and Engineering}
Six defect categories were corrected: \textbf{(i)}~two text-typed numeric columns
(\texttt{AMH} contained \texttt{"a"}; \texttt{beta-HCG II} contained \texttt{"1.99."})
coerced via \texttt{errors="coerce"};
\textbf{(ii)}~a near-empty column (\texttt{Unnamed: 44}, 2/541 non-null) dropped;
\textbf{(iii)}~inconsistent column-name whitespace stripped;
\textbf{(iv)}~an undefined cycle code (5) recoded to NaN and a binary
\texttt{Cycle\_Irregular} feature derived from the 2/4 (regular/irregular) coding;
\textbf{(v)}~physiologically impossible zeros for cycle length and endometrial thickness
set to NaN; and
\textbf{(vi)}~13 out-of-range values (e.g.\ FSH 5052\,mIU/mL, LH 2018, Vitamin D 6014,
BP systolic 12) blanked rather than corrected.

Imputation (median for continuous; mode for nominal/binary features) is performed as a
fitted step \emph{inside} each CV fold, preventing leakage of imputation statistics.

\subsection{Feature Preprocessing and Selection}
Continuous features receive median imputation then \texttt{StandardScaler};
nominal Blood Group receives mode imputation then one-hot encoding;
binary indicators receive mode imputation and no scaling.  Four feature-set strategies
are compared: all features (41), correlation filter (20), $\chi^2$-top-$k$ (15),
and Recursive Feature Elimination (15).  All selectors are scikit-learn transformers
running inside each fold.

\subsection{Exploratory Findings}
Follicle counts dominate class separation: mean $10.76$ vs $4.64$ on the right ovary,
Cohen's $d = 1.70$.  The hyperandrogenism symptom cluster (skin darkening $d=1.09$,
hair growth $d=1.04$, weight gain $d=1.03$) and irregular cycle ($d=0.87$) follow.
Hormone biomarkers (FSH, LH, TSH, prolactin) show $d < 0.18$, suggesting limited
incremental screening value.

\section{METHODOLOGY}
% ============================================================

\subsection{Pipeline Architecture}
Every model is wrapped in a single \texttt{imblearn.Pipeline}:
\[
\textit{Impute} \!\to\! \textit{Scale/Encode} \!\to\! \textit{Select} \!\to\! \textit{SMOTE} \!\to\! \textit{Classify}
\]
This structure ensures that when the pipeline is passed to \texttt{cross\_val\_score},
every fitted step is re-estimated on each training fold only.
\texttt{imblearn}'s pipeline is required (rather than scikit-learn's) because SMOTE
modifies row counts: it must execute during \texttt{fit} and be skipped during
\texttt{predict}.

\subsection{Validation Strategy}
The 541-patient dataset was split stratified 80/20 (seed 42).  All model development
uses the 432-patient training pool under \textbf{repeated stratified 10-fold CV
(3 repeats)}, yielding 30 fold scores per model.  The 109-patient test set was evaluated
exactly once at the end.  Bootstrap 95\% CIs (2000 resamples) are reported for all
test metrics.  Paired $t$-tests across identical fold scores compare each model to the
reference (Random Forest), with a practical-significance threshold of $\Delta > 0.020$.

\subsection{Models}
Nine classifiers span the useful hypothesis space for tabular clinical data
(Table~\ref{tab:models}).  The Stacking Ensemble uses LR, RF, SVM, and XGBoost as base
learners with a LR meta-learner trained on 5-fold out-of-fold probabilities.
CatBoost is included to reproduce Paper\,3's claimed 95.7\% under identical conditions.

Secondary: accuracy, precision, recall, F1, specificity, Brier score, ECE.

When SMOTE runs before the CV split, synthetic samples interpolated from training
neighbours appear in the validation fold — the model is partly scored on points derived
from its own training data.  When feature selection runs before the split, the selector
reads all 541 labels.  Table~\ref{tab:leakage} shows the inflation: +2.7 pp accuracy,
+8.3 pp F1.  This is not proof that reviewed papers made these mistakes; rather, it
shows that 98--99\% accuracy on this 541-row dataset is reachable through methodology
alone.

\subsection{Robustness}
\textbf{Nested CV:} Selection bias (flat vs.\ nested) is 0.0017 AUC --- negligible.

\section{EXPLAINABLE AI (SHAP)}
% ============================================================

SHAP decomposes each prediction into additive contributions from individual features,
satisfying local accuracy and consistency axioms \cite{lundberg2017shap}.  Values are
computed on the held-out test set and explain the model's \emph{predictions}, not
biological causality.

and ``refer-none'' defaults across the clinically plausible threshold range (5--80\%).

% ============================================================
\section{DISCUSSION}
% ============================================================

\textbf{Leakage inflates results, not algorithms.}
The most replicable finding of this study is that protocol differences alone produce
$+2.7$ pp accuracy on this dataset.  Papers~4 and 5 report 98.87--99.32\%; the leakage
experiment shows this is achievable without any algorithmic improvement.

\textbf{Statistical significance $\neq$ practical significance.}
Paired $t$-tests across 30 folds flag SVM ($p=0.028$, $\Delta=-0.017$) as significantly
worse than RF.  No clinical decision should depend on 0.017 AUC, and no model selection
should be made on that basis.  Only KNN is genuinely inferior.

\textbf{Blood panel vs.\ ultrasound.}
FSH, LH, and AMH show Cohen's $d < 0.18$.  Adding nine endocrine assays buys $+0.011$
AUC; adding follicle counts buys $+0.062$.  For screening, the blood panel is not worth
the cost.

\textbf{ML improves sensitivity; the rule dominates discrimination.}
The Rotterdam rule captures 94.3\% of ML discriminative ability.  ML's contribution is
converting the same signal into 8 more detected cases at the cost of 2 extra false alarms.

\textbf{Literature comparison.}
Papers 3--5 report 95.7--99.3\% on the same dataset using single splits without stated
leakage controls (Table~\ref{tab:literature}).  This study's 91.7\% is obtained under a
30-fold leak-free protocol with bootstrap CIs.

\section{LIMITATIONS}
% ============================================================

\begin{enumerate}[leftmargin=*,topsep=1pt,itemsep=1pt,label=\arabic*.]
\item \textbf{Predictor--label circularity.} Follicle count is the strongest SHAP
  feature \emph{and} one of the three Rotterdam criteria used to assign the label.
  The full model automates the Rotterdam criteria rather than discovering new biology.
\item \textbf{Small test set.} With 36 positive test cases, the 95\% CI on recall
  spans $\pm12$ pp.  Cross-validated estimates are more reliable.
\item \textbf{Hospital selection bias.} PCOS prevalence is 32.7\% in this cohort versus
  the 8--13\% population estimate, reflecting a hospital-attending sample.
\item \textbf{No external validation.} Generalisability to other populations is not
  established; a structural limitation acknowledged in the project's TRIPOD+AI checklist.
\item \textbf{Ambiguous column semantics.} \texttt{Cycle length(days)} has median 5
  and range 2--12, suggesting bleeding duration rather than a 28-day cycle interval.
\item \textbf{Unblinded assessment.} Symptom features were recorded by clinicians who
  also made the diagnosis, introducing potential ascertainment bias.
\end{enumerate}

% ============================================================
\section{ETHICAL AND CLINICAL CONSIDERATIONS}
% ============================================================

This framework is an academic ML screening prototype and must not be used as a
standalone clinical diagnostic system.  PCOS diagnosis requires the Rotterdam criteria
applied by a qualified clinician.  Any deployment would require prospective external
validation, regulatory assessment, ethics approval, and compliance with applicable data
protection regulations.  Model outputs should be communicated as probabilistic screening
indicators with explicit uncertainty bounds, not binary diagnoses.

% ============================================================
\section{CONCLUSION}
% ============================================================

This study builds a leakage-free ML screening pipeline for PCOS, achieving CV ROC-AUC
$0.957 \pm 0.017$ and test AUC $0.945$ [CI: 0.887, 0.991] with a Random Forest on 20
correlation-selected features.  The primary methodological contribution is a measured
demonstration that a leaky protocol inflates accuracy by $+2.7$ pp and F1 by $+8.3$ pp
on identical data.  SHAP analysis confirms that predictions align with the Rotterdam
criteria, and the questionnaire-only tier recovers 93\% of the full model's AUC without
any laboratory or ultrasound access.  The model's clinical contribution over the Rotterdam
follicle rule is 8 additional detected cases at the cost of 2 extra false alarms.
External validation is required before any real-world deployment.
